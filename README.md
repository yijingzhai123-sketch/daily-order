# 🍽️ 每日点菜 - 微信点菜小程序

> 一款简洁优雅的每日点菜小程序，告别"今天吃什么"的选择困难症！

## ✨ 功能特点

- **每日精选** - 首页随机推荐8道菜品，每天都有新发现
- **六大品类** - 热菜、凉菜、汤品、主食、饮品、甜品，38道经典菜品
- **智能搜索** - 按名称、描述、标签快速查找菜品
- **购物车** - 底部浮动购物车，实时计算总价
- **一笔下单** - 简洁流畅的下单流程，确认后自动生成订单
- **订单历史** - 完整记录每笔订单，清晰可查
- **消费统计** - 个人中心展示订单数、累计消费、最爱品类

## 📱 界面预览

| 首页 | 点餐 | 订单 | 我的 |
|------|------|------|------|
| 每日精选/热门推荐 | 分类浏览/搜索/购物车 | 订单历史/详情 | 消费统计/设置 |

## 🎨 设计风格

- **主色调**: 暖橙色 (#FF6B35) - 激发食欲
- **配色**: 白色卡片 + 浅灰背景 - 现代简洁
- **布局**: 四标签底部导航 - 操作便捷

## 🛠️ 技术栈

- 微信小程序原生框架 (WXML + WXSS + JS)
- 本地存储 (wx.Storage)
- 无后端依赖，开箱即用


## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/yijingzhai123-sketch/daily-order.git
```

### 2. 打开微信开发者工具

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目目录 `daily-order`
3. 填入你的 AppID（或使用测试号）

### 3. 预览

点击"预览"，扫码即可在手机上体验。

## 📝 AppID 配置

编辑 `project.config.json`，将 `appid` 字段修改为你自己的小程序AppID：

```json
{
  "appid": "你的AppID"
}
```

> 如果仅用于本地开发测试，可保持默认的测试AppID。

## 📋 菜品数据

所有菜品数据位于 `utils/dishes.js`，包含：

- 6大分类、38道经典菜品
- 真实价格参考
- 辣度标识 (0-4级)
- 菜品标签和描述

可按需修改或扩展菜品数据。
